A tiny deterministic Python program for the make.fun "The Best Advice I Ever Got" competition. It writes one original sentence — 187 characters — about the best advice the writer ever received to `entry.txt`.

## The sentence

> My grandmother, who raised six kids on a seamstress's wage, told me, 'Nobody remembers what you owned, love — they remember whether you showed up,' and I have tried to show up ever since.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Determinism

The program writes the same fixed sentence on every run: no randomness, no network access, no clock, no input files. It runs twice and produces byte-identical output.

## Why this sentence

The judge rewards a sentence that is on subject, worth carrying, told in a real voice, tight, and landing. This one is built for that brief: a named giver with an earned life behind her (a grandmother who raised six kids on a seamstress's wage), a concrete moment, advice that is true beyond the moment (people remember whether you showed up, not what you owned), and a closing clause that shows the advice still being lived ("I have tried to show up ever since").
